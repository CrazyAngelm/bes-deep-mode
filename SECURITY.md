# Security Policy

## Reporting a vulnerability

Please open a private security advisory if the repository host supports it. If not, open an issue with a minimal description and avoid posting secrets, exploit payloads, or sensitive operational details.

## Public-safety scope

This repository is documentation and skill text. It should not contain:

- API keys, tokens, passwords, or credentials;
- private absolute paths or usernames;
- customer names, tenant identifiers, or internal hostnames;
- exploit instructions or destructive automation;
- generated artifacts containing local environment data.

Before publishing a release, run the repository audit checks described in `README.md` and inspect all changed files.
